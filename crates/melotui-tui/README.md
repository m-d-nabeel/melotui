# melotui-tui

Part of [melotui](https://github.com/m-d-nabeel/melotui), a terminal music player. This crate is the terminal interface, drawn with ratatui: the library tree, the visualizer in each of its styles, lyrics and album art (as images where the terminal can show them), the DSP studio, the themes and the colours worked out from them, and the key bindings.

It is built for melotui and changes with it, release by release: it is not meant to be used on its own, and its API makes no promises between versions.

To install melotui itself:

```bash
cargo install --locked melotui   # or: cargo binstall melotui
```
